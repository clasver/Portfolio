### Run Locally

Just open `index.html` in a browser, or serve the folder:

```bash
git clone https://github.com/clasver/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Then visit `http://localhost:8000`.

### Contents

- `index.html` — single page site
- `assets/css/style.css` — styles (design tokens documented in `style-guide.md`)
- `assets/js/script.js` — nav toggle, back-to-top, contact form handler
- `assets/images/` — photos and portfolio backgrounds
- `assets/cv/Marvilyn-Calibuso-IT.pdf` — downloadable CV
