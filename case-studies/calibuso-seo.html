Technical SEO Checklist

  • Favicon uploaded (32×32 px .ico)
  • XML sitemap generated and submitted to Google Search Console
  • Robots.txt configured (disallow /wp-admin/, allow public pages)
  • Schema markup (LocalBusiness) added via RankMath/Wix SEO Wiz
  • Mobile-friendly design (tested with Google Mobile Friendly Test)
  • Page speed optimized (GTmetrix =?2s, PageSpeed Insights ✓ 80)
  • SSL/HTTPS enforced
  • Canonical tags present (self-referencing)
  • Breadcrumbs enabled (RankMath/Wix)
  • Custom 404 page with search box and link to Home
